# 参考图转角色设定图提示词（图生图模式）

基于提供的参考图片，提取角色的面部五官特征、发型、体型和服装款式，生成专业级多视图角色设定图。

## 画风优先级规则

画风由用户选择的风格指令决定，严格遵循风格指令进行生成。
参考图仅用于保持角色身份特征（五官、发型、体型、服装结构），不能覆盖用户指定画风。
仅在未提供风格指令时，才可参考原图画风。

## 角色设定图版式要求

生成一张专业角色设定图（Character Sheet），采用十字分割布局：

### 左侧列（1/4宽度）

**上半部分（3/4高度）：正面特写**
- 角色正面面部特写，完整展示正脸
- 必须清晰展示五官细节：眼型、鼻型、唇型、睫毛、眉毛
- 突出辨识标记：痣的精确位置、疤痕、酒窝、雀斑
- 这是 ControlNet/IP-Adapter 的面部锚点——必须极其精细
- 中性平静表情，直视镜头

**下半部分（1/4高度）：表情表（Expression Sheet）**
- 横排展示4种不同情绪的面部特写：
  1. 开心/微笑 — 面部喜悦时的形态
  2. 生气/皱眉 — 面部愤怒时的五官变形
  3. 悲伤 — 下垂的五官、低垂的眼眸
  4. 惊讶 — 扬眉、睁大眼、张嘴
- 表情表告诉AI五官在不同情绪下如何变形
- 防止生成"面瘫脸"或五官乱飞

### 右侧列（3/4宽度）

**上半部分（2/3高度）：旋转视图（Turnaround）**
- 从左到右依次展示角色全身的4个视角：
  1. 正面全身（正面直视镜头）
  2. 3/4侧面全身（微角度，展示立体感）
  3. 侧面全身（完整侧面轮廓）
  4. 背面全身（背对镜头）
- 4个视角必须是完全相同的角色，保持以下一致：
  - 体型比例和身高
  - 面部五官特征和表情（中性/平静）
  - 服装细节、配饰和颜色
  - 发型和发量
- 各视角人物大小必须一致
- 这是确保360度一致性的核心元素

**下半部分（1/3高度）：动作姿态参考**
- 横向均匀排列2-3个动作姿态，展示服装行为：
  - 坐姿（展示服装褶皱和折痕变化）
  - 跑动/运动姿态（展示面料动态和垂坠）
  - 可选：双臂交叉站立或其他自然姿态
- 人物之间必须保持充足间距，与上方旋转视图4个视角的间距保持一致，避免相邻姿态之间出现覆盖或重叠
- 这对保持服装一致性非常关键——衣服的褶皱、垂坠和拉伸方式很重要
- 服装细节必须与上方旋转视图保持一致

## 生成规则

1. 忽略原图的具体色调和光线
2. 使用自然柔和的摄影棚灯光，光照均匀
3. 绘制正常美观的人体比例
4. 不要复制原图的画质、模糊、噪点或瑕疵
5. 生成的图像必须清晰锐利、细节丰富、专业品质
6. 旋转视图中的角色表情应为自然平静的中性表情，目光正视镜头
7. 正面特写应高度精细，适合 ControlNet 面部锁定使用
8. 表情表中的面部应清晰展示情绪引起的五官变形
9. 动作姿态必须清晰展示服装褶皱和垂坠变化

## 背景要求

- 整张设定图使用纯白色背景
- 无背景景物、无渐变色、无装饰元素
- 确保角色可以被干净地提取用于后续合成

## 缺失部位自动补齐

如果参考图是半身或部分身体，请根据服装风格和人物特征合理补全未露出的部位：
- **缺少下半身**：根据上衣风格推断并绘制匹配的裤装/裙装
- **缺少脚部**：根据整体穿搭风格添加合适的鞋款
- **缺少手部/手臂**：根据姿态合理补全
- 保持整体风格一致，确保补全的部分与可见部分协调统一
