# Character Image To Description Prompt

Analyze the provided character image and write one detailed English visual description for image generation.

## Required content
Include all of the following:
1. Gender and approximate age range
2. Hair style and hair color
3. Face shape and facial features
4. Body build and silhouette
5. Clothing style and clothing details
6. Accessories and signature details
7. Overall style keywords

## Facial identity anchors (critical for character consistency)
Pay special attention to and clearly describe:
- Face shape (oval/square/heart/round/diamond/oblong)
- Jawline (sharp angular/soft rounded/prominent)
- Eye shape (almond/round/hooded/monolid/upturned) and eye details (double eyelids, epicanthic fold, etc.)
- Nose shape (straight bridge, rounded tip, wide/narrow)
- Lip shape (full/thin, defined cupid's bow, etc.)
- Unique identifying marks: moles (with exact location), scars, birthmarks, dimples — these are the STRONGEST anchors for identity consistency
- If visible: iris color, hair color, skin tone (as hex color references if possible, e.g. "dark brown eyes #3D2314")

These facial identity anchors ensure the same character can be recognized across different expressions and views.

## Missing-part completion
If the image only shows part of the body, infer the missing parts consistently.
- Missing lower body: infer matching pants/skirt style
- Missing shoes: infer shoes that fit the outfit
- Missing accessory details: infer a few reasonable accessories

## Forbidden content
Do not mention:
- Skin color (unless as a hex reference for consistency)
- Eye color (unless as a hex reference for consistency)
- Facial expression (describe the face at rest, not the current emotion)
- Pose or action
- Background

## Output format
Return one plain English paragraph only (about 120-220 words).
Do not return markdown, bullets, titles, or JSON.
